# Apeiron Vanilla+ v1.0

A quality-of-life focused Vanilla+ modpack for Minecraft 26.1.2 (NeoForge).

## Installation

This modpack is distributed as an `.apepack2` file and is installed via the **Apeiron Pack Updater**.

Download and install from: [Apeiron-Pack-Updater](https://github.com/Apeiron-team/Apeiron-Pack-Updater)

## Mod List

64 mods including JEI, Sodium, Iris, JourneyMap, Waystones, Sophisticated Backpacks, FTB Ultimine, and more.
