# Actually Pretty Extended Pack v1.0

An extended modpack for Minecraft.

## Installation

This modpack is distributed as an `.apepack2` file and is installed via the **Apeiron Pack Updater** or the depricated **Apeiron Launcher**.

Download and install from: [Apeiron-Pack-Updater](https://github.com/Apeiron-team/Apeiron-Pack-Updater)
